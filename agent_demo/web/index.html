    样例与使用说明

    上方可切换离线 Mock、本地资料＋真实模型、联网研究 Agent。联网模式须先选服务商，再输入对应 Key 检测或验证推荐模型；Key 只发给所选服务商。

    1. 选择运行方式，展开“发起新研究”并输入主题；本地两种模式仅支持固定的2024新能源汽车资料，联网模式可输入其他主题。
    2. 联网模式会保存搜索动作与网页引用；模型引用的陈述必须打开原文人工核对。
    3. 逐条采用或排除候选陈述后，模型只基于已采用内容起草报告；报告还需第二次人工确认才可下载 Markdown 或 PDF。
    4. 点报告引用查看来源；左侧“任务列表”可切换运行记录。

    “查看样例”载入固定离线样例，不重新执行。联网搜索和智谱模型检测可能产生费用；网页日期与事实真实性由人工核对。
